# SentinelRoot v6.0 — Obsidian Tactical Root Command Center

Полнофункциональный центр телеметрии экранного времени, сетевого трафика, защиты USB и отложенного автоудаления (Root).

## 10 Модулей безопасности и телеметрии (v6.0)
1. **Telegram-отчёты (`TelegramNotifier.kt`)**: Прямая отправка через `HttpURLConnection` (таймаут 5 сек) на `api.telegram.org` без промежуточного сервера (предупреждение за 5 мин до очистки, отчёт после очистки, тревога Panic Lockdown и USB-подключение).
2. **Скрытый вход через «Календарь» (`DecoyCalendarPage`)**: Иконка и название в лончере переключаются на «Календарь». Для входа нажмите **3 раза подряд на дату 5 февраля (5.02)** в течение 3 секунд и введите PIN `9058`.
3. **Пароль `9058` везде и PBKDF2**: Все PIN-коды хранятся в `SharedPreferences` в виде `PBKDF2WithHmacSHA256` (10 000 итераций + 16 байт случайной соли).
4. **Самоуничтожение через 25 минут (`SelfDestructReceiver`)**: При 3 неверных вводах PIN в календаре приложение закрывается и ставит точный будильник `AlarmManager` на 25 минут вперёд. Отменить можно в разделе «Часовой» по PIN `9058`.
5. **Тихий Wipe (Идея 175)**: Перезаписывает целевые файлы случайными данными блоками по 64 КБ (`SecureRandom`), сохраняя размер файла и исходный `lastModified` (`mtime`).
6. **Расширенный «Часовой»**: Выбор точного времени срабатывания (`TimePicker`), чекбоксы целей (Приложения / Папки / Полный сброс с вводом слова `СБРОС`).
7. **Блокировка USB / ADB / MTP (`UsbGuardReceiver`)**: По умолчанию отключает `sys.usb.config` и `adbd`, контролирует порты `5555` и `5037`.
8. **Счётчик попыток отключения и Panic Lockdown (`PanicService`)**: При 3 попытках саботажа отключает все беспроводные интерфейсы, выставляет яркость 100% и включает циклическую сирену `assets/alarm_siren.wav`.
9. **Доступ к ПК (`PcAccessPage`)**: Временная разблокировка `mtp,adb` на 5 / 15 / 30 / 60 минут по отдельному `PC-Access-PIN` (`9058`).
10. **Монитор скорости интернета (`SpeedMonitor.kt` + `SpeedBadge`)**: Чтение `/proc/net/dev` (с fallback на `TrafficStats`), график Sparkline на 30 точек в верхнем HUD и живая скорость по каждому приложению.
